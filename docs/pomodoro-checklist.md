# Pomodoro Session Checklist

A short procedural checklist for a single focused work session. Work through
each phase in order and mark items off as they are completed.

## Before the session

- [ ] Choose one task for this session and write it down.
- [ ] Break the task into steps that fit the session.
- [ ] Clear the desk and screen of unrelated items.
- [ ] Decide what counts as progress for this session.
- [ ] Write down anything you need before starting.

## During the session

- [ ] Start only when the chosen task is ready to begin.
- [ ] Work on the chosen task and set aside unrelated requests.
- [ ] Note interruptions as they arrive instead of acting on them.
- [ ] Pause once to confirm the work still matches the chosen task.
- [ ] Stop at the end of the session even if a step is unfinished.

## After the session

- [ ] Note what was finished and what remains.
- [ ] Write the next concrete step for the task.
- [ ] Close files and windows that are no longer needed.
- [ ] Record any follow-up that is not part of this task.
- [ ] Decide whether the next session continues this task.
